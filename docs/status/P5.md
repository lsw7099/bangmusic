## 구현한 것 (P5 커밋 eca014a ~ da0fd6a)

- **공통 상태**: 배너(오프라인·서버 연결 불가·세션 만료·점검·업데이트·같은 주소 다른 서버), 접근 취소 전체 화면, 재로그인 시트(현재 화면 유지).
- **S1**: 저장된 서버, 서버 확인 카드, 같은 주소의 다른 서버 경고, 로컬 네트워크 권한 안내, 로그인 실패 문구, 오프라인으로 계속, 느린 응답 취소, 큰 글씨 배치.
- **S2~S6**: 라이브러리 격자(큰 글씨면 1열)와 "다운로드한 항목만", 검색의 최근 검색어·모두 보기, 앨범·플레이리스트의 로컬 우선 표시와 고정 머리, 플레이리스트 편집·표지·충돌 처리, 첫 플레이리스트 만들기.
- **S7·S8**: 미니 플레이어 상태(준비 중·오류·오프라인 아이콘), 위로 끌기, 몰입 화면 가로 2단, 오류 줄 "다음 곡", 변환 대기 문구, 대기열 실행 취소·비우기, 가사 칩 비활성 이유, 가사 출처 표기.
- **S10·S11**: 설정 전체(서버·재생·다운로드·가사·화면·개인정보·앱), 구매 화면 골격. 판매 방식은 README §4 미결이라 구매 버튼은 비활성이다.
- **탭 동작**: 다시 누르면 맨 위로, 검색 탭은 검색창 초점, 마지막 탭 복원.

## 알려진 공백 (P5 범위에서 하지 않은 것)

- 탭별 화면 스택은 앱을 다시 시작하면 복원하지 않는다(마지막 탭만 복원).
- 보조 서버 주소(LAN·외부 주소 두 개)는 구현하지 않았다.
- 서버에서 삭제된 곡의 다운로드 자동 정리는 구현하지 않았다(목록에는 "재생할 수 없는 곡"으로 표시된다).
- 대기열 상태는 아직 SharedPreferences에 저장한다(로컬 DB로 옮기지 않음).
- 매트릭스의 △ 항목: 로딩 그림, 다음 페이지 실패, 검색 중 이전 결과 흐림, S7 오프라인 아이콘, S8 대기열 빈 목록·오프라인 흐림, S10 세션 목록 상태. 모두 코드는 있고 그림이나 단독 테스트가 없다.
- 결제 오류 3종(취소·보류)은 판매 방식이 정해진 뒤에 확인한다.
