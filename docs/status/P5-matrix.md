- **그림**: [`evidence/p5-gallery/`](evidence/p5-gallery/index.md). `flutter test --tags screenshots test/screenshots/gallery_test.dart`로 만든다. 가짜 서버·가짜 플레이어, 360×780dp. 수준 **L1**.
- **테스트**: `app/test/` 위젯 테스트(L1). 일반 실행은 `flutter test '--exclude-tags=integration,screenshots'`, 195개 통과(2026-10-04).
- **실기기**: P4에서 SM-S948N(Android 16)으로 확인한 항목(L3). P5의 회전·글자 2배·TalkBack 실기기 점검(FN-19)은 아직 하지 않았다.

표시: ✅ 증거 있음 · △ 구현했으나 그림이나 테스트가 부분적 · ✗ 미구현
