# 04. 모바일 UI 명세

Android 1차 기준이며 iOS에서도 같은 구조를 쓴다. 기존 Windows 앱의 특징(큰 플레이리스트 표지, 붉은 강조색, LP 몰입 화면, 3단 가사)을 **모바일용으로 다시 설계**한 것이며 데스크톱 화면의 복사가 아니다. 색·형태·이름은 독자적으로 정했고 특정 상용 서비스의 화면을 본뜨지 않는다(05장 §8.7).

---

## 1. 설계 원칙

1. **한 손 조작**: 주요 동작은 화면 아래 절반에 둔다. 터치 영역 최소 48×48dp, 간격 8dp 이상.
2. **hover 없음**: 모든 기능은 보이는 버튼, 길게 누르기(보조), 또는 `⋮` 메뉴로 도달한다. 길게 누르기로만 가능한 기능은 두지 않는다.
3. **상태를 숨기지 않는다**: 오프라인·다운로드·세션 상태는 항상 같은 자리에서 같은 모양으로 보인다.
4. **로컬 우선**: 화면은 로컬 DB로 먼저 그리고 서버 응답으로 갱신한다. 네트워크 때문에 빈 화면에서 기다리게 하지 않는다.
5. **색만으로 전달하지 않는다**: 상태는 아이콘+문구를 함께 쓴다.

## 2. 내비게이션과 탭 동작

```text
┌──────────────────────────────┐
│ 상태 배너 (필요할 때만)         │
│                              │
│        탭별 화면 스택           │
│                              │
├──────────────────────────────┤
│ 미니 플레이어 (대기열 있을 때)   │
├──────────────────────────────┤
│  홈   라이브러리   검색   다운로드 │
└──────────────────────────────┘
```

| 탭 | 루트 화면 | 비고 |
| --- | --- | --- |
| 홈 | S2 | 우상단 프로필 버튼 → 설정(S10) |
| 라이브러리 | S3 | 플레이리스트 / 앨범 / 아티스트 / 곡 |
| 검색 | S4 | |
| 다운로드 | S9 | 진행 중 개수 배지, 실패가 있으면 경고 점 |

탭 동작 규칙:

- 탭마다 **독립된 화면 스택**과 스크롤 위치를 유지한다. 탭을 바꿨다 돌아오면 보던 화면 그대로다.
- 현재 탭을 다시 누르면: 스택이 깊으면 루트로 돌아가고, 이미 루트면 맨 위로 스크롤한다. 검색 탭 루트에서는 검색창에 초점을 준다.
- 시스템 뒤로 가기: 스택에서 한 단계 → 탭 루트면 홈 탭으로 → 홈 루트면 앱을 백그라운드로(재생은 계속). Android 예측형 뒤로 가기 동작을 지원한다.
- 몰입 화면(S8)은 탭 위에 덮이는 전체 화면 시트다. 뒤로 가기 또는 아래로 끌기로 닫는다. 탭 스택에 쌓이지 않는다.
- 가로 화면·태블릿(폭 600dp 이상): 하단 탭이 좌측 레일로 바뀌고, 미니 플레이어는 하단 전체 폭 유지.
- 프로세스 재시작 후 마지막 탭과 각 탭의 스택을 복원한다.

## 3. 디자인 토큰

값은 제안이며, 대비는 구현 시 측정 도구로 확인한다(본문 4.5:1, 큰 글자·아이콘 3:1 이상이 수용 기준).

### 3.1 색

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `color.bg` | `#FBF8F7` | `#121011` | 화면 배경 |
| `color.surface` | `#FFFFFF` | `#1E1A1B` | 카드, 시트, 미니 플레이어 |
| `color.surfaceAlt` | `#F3EDEC` | `#2A2526` | 입력란, 칩, 자리표시자 |
| `color.outline` | `#E1D7D6` | `#3A3435` | 구분선, 테두리 |
| `color.text` | `#1C1718` | `#F4EEEE` | 본문 |
| `color.textMuted` | `#6B5F61` | `#B5A9AB` | 보조 문구 |
| `color.textDisabled` | `#A89D9E` | `#6E6466` | 비활성, 재생 불가 곡 |
| `color.accent` | `#D7263D` | `#FF6B7D` | 주 동작, 재생 중 표시, 진행 막대 |
| `color.onAccent` | `#FFFFFF` | `#2A0A0F` | 강조색 위 글자·아이콘 |
| `color.accentSoft` | `#FBE3E6` | `#40161C` | 선택된 칩·행 배경 |
| `color.success` | `#1E7A46` | `#5BD08A` | 다운로드 완료 |
| `color.warning` | `#9A5B00` | `#F2B34C` | 대기, 업데이트 있음 |
| `color.danger` | `#B3261E` | `#FF8A80` | 실패, 삭제 |
| `color.scrim` | `#000000` 40% | `#000000` 60% | 시트 뒤 가림막 |

- 강조색 붉은 계열은 기존 앱의 정체성을 잇되 값은 독자적으로 정했다. 라이트 `#D7263D`는 흰 배경 대비 약 4.9:1이다.
- **[P5 측정]** 실제 쓰는 글자·배경 조합 39개를 WCAG 2.x 공식으로 측정해 모두 기준을 넘는다(`app/test/ui/contrast_test.dart`가 매번 확인). 예외 하나: 라이트 `accent` 글자 / `accentSoft` 배경은 4.07:1이라 **강조 배경 위 글자는 `text`(본문색) + 굵게**를 쓴다(상태 배너의 동작 버튼).
- `danger`와 `accent`가 모두 붉은 계열이므로, 파괴적 동작은 색이 아니라 **아이콘(휴지통)과 확인 문구**로 구분한다.
- 몰입 화면 배경은 표지에서 뽑은 색을 어둡게 눌러 쓴다(명도 상한 고정 → 글자 대비 보장). 표지가 없으면 `color.bg`.
- 테마: 시스템 따름(기본) / 라이트 / 다크.

### 3.2 글자

기기 기본 글꼴 사용(한글·가나·한자 혼용 줄에서 폴백이 자연스럽고 글꼴 라이선스 문제가 없다). 크기 단위 sp, 시스템 글자 크기 설정을 따른다.

| 토큰 | 크기/줄 높이 | 굵기 | 용도 |
| --- | --- | --- | --- |
| `type.display` | 28/36 | 700 | 홈 인사, 몰입 화면 곡 제목 |
| `type.title` | 20/28 | 700 | 화면 제목, 구획 제목 |
| `type.body` | 16/24 | 400 | 목록 제목, 본문 |
| `type.bodyStrong` | 16/24 | 600 | 재생 중 곡 제목 |
| `type.caption` | 13/18 | 400 | 아티스트, 보조 정보 |
| `type.lyricActive` | 22/32 | 700 | 현재 가사 줄(원문) |
| `type.lyric` | 18/28 | 500 | 나머지 가사 줄 |
| `type.lyricSub` | 14/22 | 400 | 발음·번역 줄 |

일본어 제목은 줄임표로 자르되 글자 중간 결합이 깨지지 않게 문자소 단위로 자른다.

### 3.3 간격·모양·동작

| 토큰 | 값 |
| --- | --- |
| `space` | 4 / 8 / 12 / 16 / 24 / 32 dp |
| 화면 좌우 여백 | 16dp(폭 600dp 이상 24dp) |
| `radius.sm / md / lg / pill` | 8 / 12 / 20 / 999 dp |
| 표지 모서리 | 목록 8dp, 큰 카드 20dp |
| `elevation.sheet` | 그림자 대신 `surface` + `outline` 1dp(다크에서 일관) |
| `motion.fast / base / slow` | 120 / 220 / 360 ms, 감속 곡선 |
| LP 회전 | 재생 중 1회전 약 1.8초(33⅓rpm), 일시정지 시 0.6초에 걸쳐 감속 정지 |

"동작 줄이기"(시스템 애니메이션 축소 설정)가 켜져 있으면 LP 회전·표지 전환을 끄고 페이드만 쓴다.

## 4. 컴포넌트

| 컴포넌트 | 구성 | 상태·변형 |

| `SeekBar` | 막대 · 경과/남은 시간 | 끌기 중 시간 말풍선 / 버퍼 구간 표시 / 로딩 |
| `Chip` | 필터·토글 | 선택(`accentSoft` + 체크 아이콘) / 미선택 |

| `LyricLine` | 원문 · 발음 · 번역 최대 3줄 묶음 | 현재 줄 / 지난 줄(흐림) / 다가올 줄 / 동기화 없음(모두 같은 밝기) |
| `Snackbar` | 한 줄 + 실행 취소(선택) | 미니 플레이어 위에 표시 |

접근성 공통:

- 모든 아이콘 버튼에 문구 레이블(예: "다음 곡", "다운로드, 62% 진행 중").
- `TrackRow`는 스크린리더에서 한 항목으로 읽는다: "곡 제목, 아티스트, 3분 35초, 다운로드됨". 보조 동작(다음에 재생 등)은 사용자 지정 접근성 동작으로 제공한다.
- 탐색 막대는 스크린리더에서 10초 단위 증감이 가능하다.
- 초점 순서는 시각 순서와 같다. 시트가 열리면 초점이 시트 안에 갇히고 닫히면 원래 버튼으로 돌아간다.

## 5. 공통 상태

각 화면 표의 "오프라인/세션 만료/큰 글씨"는 아래 규칙에 화면별 차이를 더한 것이다.

| 상태 | 판정 | 공통 표시 |
| --- | --- | --- |
| **로딩** | 로컬 데이터 없음 + 요청 중 | `SkeletonList`. 로컬 데이터가 있으면 그것을 먼저 보이고 상단에 얇은 진행선만. |
| **빈 목록** | 요청 성공, 항목 0 | `EmptyState`(화면별 문구와 주 동작) |
| **오류** | 요청 실패, 보여 줄 로컬 데이터 없음 | `ErrorState`. 로컬 데이터가 있으면 목록 유지 + 스낵바 "새로 고치지 못했습니다". |
| **오프라인** | 기기에 네트워크 없음 | 배너 "오프라인 · 다운로드한 음악만 재생할 수 있습니다". 다운로드 안 된 항목은 흐림. |
| **서버 연결 불가** | 네트워크는 있으나 서버 무응답 | 배너 "서버에 연결할 수 없습니다 · 다시 시도". 오프라인과 문구를 구분한다. |
| **세션 만료** | `refresh_expired` | 배너 "다시 로그인이 필요합니다 · 로그인". 다운로드 재생은 가능. 로그인은 시트로 띄워 현재 화면을 잃지 않는다. |
| **접근 취소** | `session_revoked` / `account_disabled` | 전체 화면 안내 "이 기기의 접근이 취소되었습니다". 다운로드 잠김 설명, 다시 로그인 / 이 서버 삭제. |
| **서버 점검** | `503 maintenance` | 배너 "서버 점검 중입니다". 자동 재시도. |
| **서버 저장소 장애** | `503 storage_unavailable` | 재생 시 스낵바 "서버의 음악 저장소에 연결할 수 없습니다". 목록은 정상 표시. |
| **버전 불일치** | 02장 §2.2 | 서버가 낮음: 배너 또는 로그인 차단 화면. 앱이 낮음: 업데이트 안내 화면(스토어 버튼). |
| **큰 글씨** | 글자 배율 1.3 이상 | 아래 규칙 |

큰 글씨 규칙(배율 2.0까지 지원):

- 고정 높이 행 금지. 제목 2줄까지 허용 후 줄임표.
- 배율 1.3 이상: 2열 격자 → 1열 목록, 가로 스크롤 카드의 문구는 표지 아래 2줄.
- 배율 1.5 이상: 미니 플레이어는 아티스트 줄을 숨기고 제목 1줄 + 버튼, 탭 레이블은 유지(아이콘만으로 줄이지 않는다).
- 몰입 화면: 제어 버튼 크기는 고정, 제목·가사만 커진다. 가사는 화면 폭에서 자동 줄바꿈.
- 어떤 배율에서도 버튼이 화면 밖으로 밀려나지 않는다(세로 스크롤 허용).

## 6. 화면

### S1. 서버 연결 · 로그인

흐름: ① 서버 주소 입력 → ② 서버 확인 카드(이름, 버전, 인증서 상태) → ③ 사용자 이름·비밀번호 → ④ 첫 동기화.

```text
┌──────────────────────────────┐
│ BangMusic                    │
│ 내 음악 서버에 연결              │
│ ┌──────────────────────────┐ │
│ │ https://music.example.net│ │
│ └──────────────────────────┘ │
│ 서버가 없나요? 설치 안내 ↗       │
│                              │
│ [        서버 확인        ]    │
└──────────────────────────────┘
```

- 주소 입력: 스킴이 없으면 `https://`를 붙인다. `http://`를 입력하면 "보안 연결(HTTPS)만 지원합니다"와 설정 안내 링크를 보인다.
- 서버 확인 카드에 서버 이름과 주소를 다시 보여 주어 **비밀번호 입력 전에** 사용자가 대상 서버를 확인하게 한다.
- 등록된 서버가 여러 개면 이 화면 앞에 서버 선택 목록이 나온다(서버별 마지막 사용자, 세션 상태 표시).
- 앱 구매 상태는 이 화면과 무관하다. 구매 화면(S11)은 별도 흐름이다.

| 상태 | 표시 |
| --- | --- |
| 로딩 | 버튼이 진행 고리로 바뀌고 입력란 잠금. 10초 넘으면 "응답이 느립니다" + 취소. |
| 빈 목록 | 등록된 서버 없음 = 이 화면 자체(첫 실행). |
| 오류: 연결 불가 | "서버를 찾을 수 없습니다" + 점검 항목(주소, 같은 네트워크/VPN, 포트). |
| 오류: 인증서 | "서버의 보안 인증서를 확인할 수 없습니다" + 안내 링크. 무시하고 계속 버튼은 없다. |
| 오류: BangMusic 서버 아님 | "이 주소는 BangMusic 서버가 아닙니다". |
| 오류: 로컬 네트워크 권한 없음 | "집 안 네트워크의 서버에 연결하려면 권한이 필요합니다" + 권한 요청/설정 열기(Android 17 타깃 시). |
| 오류: 로그인 실패 | 비밀번호 입력란 아래 문구. 5회 실패 후 대기 시간 표시(`Retry-After`). |
| 오류: 초기 설정 필요 | "서버 설정이 끝나지 않았습니다" + 설치 안내. |
| 버전 불일치 | 서버 낮음: "서버 업데이트가 필요합니다(현재 x, 필요 y)". 앱 낮음: 스토어 버튼. |
| 오프라인 | "인터넷에 연결되어 있지 않습니다". 이미 로그인한 프로필이 있으면 "오프라인으로 계속". |
| 세션 만료(재로그인) | 사용자 이름이 채워진 로그인 시트. 서버 주소는 고정 표시. |
| 큰 글씨 | 세로 스크롤, 버튼은 키보드 위에 고정. |

### S2. 홈

```text
┌──────────────────────────────┐
│ 좋은 저녁이에요, 시원     (프로필)│
│                              │
│ ┌────────────────┐ ┌─────    │  ← 플레이리스트 주인공 카드 (가로 넘김, 폭 72%)
│ │                │ │         │     큰 표지 + 이름 + 곡 수 + ▶
│ │   큰 표지        │ │         │
│ │            (▶) │ │         │
│ └────────────────┘ └─────    │
│ 드라이브 · 42곡                 │
│                              │
│ 최근 들은 곡            모두 보기 │
│ [▢][▢][▢][▢]→                │
│ 많이 들은 곡            모두 보기 │
│ 1 ▢ 곡 제목 — 아티스트      ⋮   │

```

- 주인공 카드의 ▶는 해당 플레이리스트를 처음부터(셔플 설정 유지) 재생. 카드 본문을 누르면 S6.
- 당겨서 새로 고침.

| 상태 | 표시 |
| --- | --- |
| 로딩 | 구획별 자리표시자. 로컬 사본이 있으면 즉시 표시. |
| 빈 목록 | 플레이리스트 없음: 주인공 자리에 "첫 플레이리스트 만들기" 카드. 기록 없음: 해당 구획 숨김. 라이브러리 자체가 비었으면 "서버에 음악이 없습니다" + 서버 설정 안내. |
| 오류 | 구획 단위 `ErrorState`(다른 구획은 유지). |
| 오프라인 | 다운로드된 플레이리스트·곡만 선명, 나머지 흐림. "최근/많이 들은 곡"은 로컬 기록 기준. |
| 세션 만료 | 배너. 내용은 로컬 사본. |
| 큰 글씨 | 주인공 카드 폭 88%, 가로 구획의 카드 문구 2줄, "많이 들은 곡" 순위 숫자 유지. |

### S3. 라이브러리

상단 칩: `플레이리스트` `앨범` `아티스트` `곡` + 우측 정렬 버튼 + "다운로드한 항목만" 토글.

- 플레이리스트·앨범: 2열 격자(`CoverCard` M). 아티스트: 원형 이미지 목록. 곡: `TrackRow` 목록 + 빠른 스크롤(정렬 키 첫 글자 표시).
- 플레이리스트 칩에서 우하단 `+` 버튼으로 새 플레이리스트.
- 곡 목록은 가상 스크롤. 서버 페이지(`cursor`)를 스크롤 끝 5행 전에 미리 요청한다.

| 상태 | 표시 |
| --- | --- |
| 로딩 | `SkeletonList`/격자 자리표시자. 다음 페이지 로딩은 목록 끝에 작은 진행 고리. |
| 빈 목록 | 종류별 문구. 필터 때문에 비었으면 "다운로드한 항목이 없습니다" + 필터 끄기. |
| 오류 | 첫 페이지 실패: `ErrorState`. 다음 페이지 실패: 목록 끝에 "더 불러오지 못했습니다 · 다시 시도". |
| 오프라인 | "다운로드한 항목만" 자동 켜짐(해제 가능). |
| 세션 만료 | 배너 + 로컬 사본. |
| 큰 글씨 | 격자 → 1열 목록. 칩 줄은 가로 스크롤. |

### S4. 검색

- 상단 검색창(자동 초점은 탭 재선택 시에만). 입력 전: 최근 검색어(기기 로컬 저장, 개별 삭제·전체 삭제).
- 결과: 유형별 구획(곡 5 · 앨범 · 아티스트 · 플레이리스트) + "모두 보기"로 유형별 전체 목록(페이지네이션).
- 일본어: 가나/전각·반각 차이는 서버가 흡수한다(02장 §3). 입력기 조합 중에는 요청하지 않는다.

| 상태 | 표시 |
| --- | --- |
| 로딩 | 결과 영역 자리표시자. 이전 결과는 흐리게 유지. |
| 빈 목록 | "‘질의어’에 대한 결과가 없습니다" + 철자 확인 안내. |
| 오류 | 구획 내 `ErrorState`. |
| 오프라인 | 로컬 검색으로 전환, 상단에 "다운로드한 음악에서 검색 중" 표시. |
| 세션 만료 | 로컬 검색 + 배너. |
| 큰 글씨 | 구획 제목과 "모두 보기"가 두 줄로 나뉨. |

### S5. 앨범 · S6. 플레이리스트

```text
┌──────────────────────────────┐
│ ←                         ⋮  │
│        ┌──────────┐          │
│        │  큰 표지   │          │
│        └──────────┘          │
│ 이름                          │
│ 아티스트 · 2024 · 12곡 · 48분   │
│ [ ▶ 재생 ] [ 🔀 셔플 ] [ ⤓ ]   │
│ ─────────────────────────    │
│ 1  곡 제목              ✓  ⋮  │
│ 2  곡 제목              ◔  ⋮  │
└──────────────────────────────┘
```

- `⤓` 다운로드 버튼: 없음 → 대기 → 진행(n/m) → 완료. 완료 상태에서 누르면 "다운로드 삭제" 확인.
- 스크롤하면 표지가 줄어들고 이름·재생 버튼이 상단 막대에 고정된다.
- 플레이리스트 전용: 편집 모드(순서 끌기 손잡이, 삭제, 이름·설명 수정), 표지 변경(사진 선택 → 정사각 자르기 → 업로드), 곡 추가.
- 플레이리스트 항목 중 `available=false`는 "재생할 수 없는 곡"으로 흐리게 표시하고 삭제만 가능.
- 표지 이미지 선택에는 시스템 사진 선택기를 쓴다(저장소 전체 권한을 요청하지 않는다).

| 상태 | 표시 |
| --- | --- |
| 로딩 | 머리 부분은 목록에서 넘겨받은 정보로 즉시 표시, 곡 목록만 자리표시자. |
| 빈 목록 | 플레이리스트: "아직 곡이 없습니다" + 곡 추가. 앨범은 해당 없음. |
| 오류 | 목록 영역 `ErrorState`. 404면 "삭제되었거나 접근할 수 없습니다" + 뒤로. |
| 충돌 | 편집 저장 시 `version_conflict`: "다른 기기에서 변경되었습니다" + 최신 내용 보기. |
| 오프라인 | 다운로드된 곡만 선명. 재생/셔플은 다운로드된 곡만 대상으로 동작하고 버튼 아래 "다운로드한 n곡 재생" 표시. 편집은 가능(동기화 대기 표시). |
| 세션 만료 | 로컬 사본, 다운로드·편집 버튼 비활성 + 배너. |
| 큰 글씨 | 버튼 줄이 2행으로, 보조 정보는 줄바꿈. |

### S7. 미니 플레이어

- 위치: 탭 바 바로 위, 높이 64dp(큰 글씨에서 가변). 대기열이 없으면 숨김.
- 동작: 누르기 → 몰입 화면 / 위로 끌기 → 몰입 화면 / 좌우 넘기기 → 이전·다음 곡 / 버튼 → 재생·일시정지, 다음.
- 넘기기 동작과 같은 기능을 하는 버튼이 몰입 화면에 있으므로 넘기기는 보조 수단이다.

| 상태 | 표시 |
| --- | --- |
| 로딩/버퍼링 | 재생 버튼 자리에 진행 고리, 제목 유지. 변환 대기면 보조 줄에 "서버에서 준비 중". |
| 오류 | 느낌표 아이콘 + "재생할 수 없습니다". 누르면 사유와 다음 곡 버튼. |
| 오프라인 | 다운로드본 재생 중이면 평소와 같음 + 작은 오프라인 아이콘. |
| 세션 만료 | 다운로드본은 재생 가능. 스트리밍 곡이면 오류 상태. |
| 큰 글씨 | 아티스트 줄 숨김(배율 1.5 이상), 버튼 크기 유지. |

### S8. 몰입 화면 (LP · 가사 · 대기열)

```text
┌──────────────────────────────┐
│ ⌄   드라이브 에서 재생 중     ⋮  │
│                              │
│          ╭────────╮  ╱       │
│        ╭─┤ 표지   ├─╮╱ 톤암    │   ← LpDisc
│        ╰─┤ 라벨   ├─╯        │
│          ╰────────╯          │
│                              │
│ 곡 제목                    ⤓  │
│ 아티스트                       │
│ ●━━━━━━━━━━○───────────      │
│ 1:12                  -2:23  │
│   🔀    ⏮    ( ▶ )    ⏭    🔁 │
│                              │
│   [ LP ]  [ 가사 ]  [ 대기열 ]  │
└──────────────────────────────┘
```

- 하단 3구획 전환(`LP`/`가사`/`대기열`). 좌우 넘기기로도 전환. 재생 제어 줄은 세 구획에서 항상 같은 자리에 있다.
- **LP**: 표지를 중앙 라벨로 한 원반이 회전. 원반을 누르면 재생/일시정지. 플레이리스트에서 재생 중이면 라벨에 곡 표지를, 원반 뒤 배경에 플레이리스트 표지를 흐리게 깐다. 원반을 돌려 탐색하는 제스처는 넣지 않는다(오조작·접근성).
- **가사**: 칩 3개 `원문` `발음` `번역`으로 표시 줄을 고른다(원문은 항상 켜짐, 선택은 기억). 현재 줄을 화면 위 1/3 지점에 맞춰 자동 스크롤. 줄을 누르면 그 시각으로 탐색. 사용자가 직접 스크롤하면 자동 스크롤을 멈추고 "현재 줄로" 버튼을 띄운다. `⋮`에서 동기화 보정(±0.1초 단계, 저장은 서버의 사용자별 값).
- **대기열**: "지금 재생 중" / "다음에 재생"(`up_next`) / "이어서: 컨텍스트 이름". 끌어서 순서 변경, 밀어서 제거(실행 취소 스낵바), 대기열 비우기.
- 음질 표시: 제목 아래 작은 꼬리표로 실제 제공 형식(예: "FLAC 원본", "AAC 256 · 변환", "다운로드됨").
- 가로 화면: 좌측에 LP + 제어, 우측에 가사 또는 대기열.

| 상태 | 표시 |
| --- | --- |
| 로딩/버퍼링 | LP 라벨 위 진행 고리, 탐색 막대는 버퍼 구간 표시. 변환 대기: "서버에서 재생용 파일을 준비 중입니다". |
| 빈 목록: 가사 없음 | "가사가 없습니다". 발음/번역만 없으면 해당 칩 비활성 + 누르면 "이 곡에는 발음 가사가 없습니다". 출처가 있으면 가사 끝에 출처 표기. |
| 빈 목록: 대기열 | "이어서 재생할 곡이 없습니다". |
| 동기화 없는 가사 | 강조 없이 전체 표시, 자동 스크롤 없음, 상단에 "시간 정보가 없는 가사" 표시. |
| 오류 | LP 자리에 사유(파일 없음/형식 미지원/서버 저장소 장애/변환 실패)와 "다음 곡". 자동으로 넘어가기 전 3초 표시. |
| 오프라인 | 대기열의 재생 불가 곡 흐림 + "오프라인에서 건너뜀". 가사는 로컬 사본. |
| 세션 만료 | 상단에 얇은 배너. 다운로드본 재생은 유지. |
| 큰 글씨 | 제목 2줄, 가사는 줄바꿈하며 확대, LP 크기를 줄여 제어 줄이 화면 안에 남게 한다. 배율 1.5 이상에서는 가사 구획에서 LP를 숨긴다. |

### S9. 다운로드 관리

구획: **진행 중**(전체 일시중지/재개) · **확인 필요**(실패·잠김·업데이트 있음) · **완료**(플레이리스트/앨범/곡 묶음, 크기 표시).

- 상단 저장 공간 막대: BangMusic 사용량 / 한도 / 기기 여유.
- 항목별: 상태 문구, 진행률, 일시중지·재개·재시도·삭제.
- 상태 문구는 03장 §5.3의 상태와 1:1로 대응한다: "대기 중", "서버에서 준비 중", "받는 중 62%", "일시중지됨", "Wi-Fi 연결 대기", "네트워크 연결 대기", "저장 공간 부족", "확인 중", "완료", "실패: 사유".
- 완료 구획: 크기순/최근순 정렬, 여러 개 선택 삭제.

| 상태 | 표시 |
| --- | --- |
| 로딩 | 로컬 DB라 즉시 표시. 자리표시자 없음. |
| 빈 목록 | "다운로드한 음악이 없습니다. 앨범이나 플레이리스트에서 ⤓를 누르세요" + 라이브러리로 이동. |
| 오류 | 항목별 사유: 네트워크 / 서버에 파일 없음 / 무결성 불일치 / 저장 공간 / 서버가 바쁨. 각 사유에 맞는 동작(재시도, 공간 관리). |
| 오프라인 | 진행 중 항목은 "네트워크 연결 대기". 완료 항목은 평소대로. |
| 세션 만료 | 진행 중 항목은 "로그인 필요"로 멈춤 + 배너. 완료 항목 재생 가능. |
| 접근 취소 | 전체가 "잠김" 구획으로. 설명 + 다시 로그인 / 이 기기에서 삭제. |
| 큰 글씨 | 상태 문구는 제목 아래 줄로, 버튼은 행 끝이 아니라 다음 줄로 내려간다. |

### S11. 구매 · 복원

**[P7 결정]** 무료 설치 + 1회 구매(비소모성, 05장 §8.1). 미구매 상태에서는 **새 다운로드 시작만** 막는다. 다운로드 버튼을 누르면 "다운로드(오프라인 저장)는 구매 후 사용할 수 있습니다" 안내와 함께 이 화면으로 연결한다. 스트리밍·탐색·가사·플레이리스트와 이미 받은 곡의 재생은 그대로 둔다.

- 구성: 제품 설명 · 가격(스토어에서 받은 현지화 문자열) · 구매 버튼 · 구매 복원 · 약관/개인정보 링크.
- **음악 서버 로그인과 분리**: 이 화면은 서버 주소·서버 계정을 묻지 않으며, 구매 여부가 서버 로그인 성공/실패에 영향을 주지 않는다.

| 상태 | 표시 |
| --- | --- |
| 로딩 | 가격 자리표시자. 스토어 응답 전에는 구매 버튼 비활성. |
| 오류 | 스토어 연결 불가 / 결제 취소 / 보류 중 결제 각각 다른 문구. |
| 오프라인 | 마지막으로 확인한 구매 상태를 그대로 인정(03장 §5.8). "오프라인에서는 구매·복원을 할 수 없습니다". |
| 복원 결과 없음 | "이 스토어 계정에서 구매 내역을 찾지 못했습니다" + 도움말. |
| 큰 글씨 | 세로 스크롤, 구매 버튼 하단 고정. |
