# Google Play 등록 정보 (초안)

> 초안 — 2026-10-04. 05장 §8.6: "음악을 제공한다"는 인상을 주지 않는다. 사용자 본인 서버의 본인 음악을 재생하는 용도임을 분명히 한다. 스크린샷은 합성 표지·가상의 곡명만(`tools/make-fixtures`, 갤러리 `test/screenshots`).

**앱 이름**: BangMusic

**짧은 설명 (80자 이내)**
내 서버에 있는 내 음악을 휴대폰에서 — 스트리밍, 오프라인 저장, 일본어 가사 발음까지.

**자세한 설명**

BangMusic은 집 NAS·미니 PC에 직접 설치하는 BangMusic 서버와 함께 쓰는 음악 앱입니다. 앱 자체는 음악을 제공하지 않습니다. 내가 가진 음악 파일을 내 서버에 두고, 휴대폰에서 듣습니다.

• 내 서버의 앨범·아티스트·곡 탐색과 검색(가타카나·히라가나·전각/반각을 같은 글자로)
• 원본 음질 그대로 스트리밍, 데이터를 아끼려면 AAC로
• 오프라인 저장: 앨범·플레이리스트를 받아 두면 비행기 모드에서도 재생 (1회 구매)
• 싱크 가사: 원문 · 한글 발음 · 번역을 함께 표시. 일본어 가사의 한글 발음은 서버가 자동으로 만들어 줌
• 플레이리스트, 셔플·반복, 잠금화면·알림·블루투스 제어
• 여러 서버, 가족 계정

개인정보: 앱은 내가 등록한 서버와 Google Play 외에는 어디와도 통신하지 않습니다. 분석·광고·오류 보고 도구가 없습니다.

서버 설치: BangMusic 서버는 무료(MIT 라이선스)입니다. Docker 또는 Proxmox에 설치하는 방법은 [설치 문서 주소]를 보세요.

요금: 앱 설치와 스트리밍은 무료입니다. 오프라인 저장(다운로드)은 앱 안에서 한 번 구매하면 계속 쓸 수 있습니다.

**데이터 보안 양식**: 수집하는 데이터 없음 · 공유하는 데이터 없음 · 전송 중 암호화(사용자 서버는 HTTPS만 허용) · 데이터 삭제 요청: 앱 안에서 서버 계정 삭제 가능.

**카테고리**: 음악 및 오디오 · **콘텐츠 등급**: 설문으로 정함(사용자 생성 콘텐츠 없음, 앱이 콘텐츠를 제공하지 않음)
